## 建议使用方法

### 1. 做文献综述时

先阅读总览文件，按主题找到相关文献，再从单篇精读中学习如何提炼文献创新点。

### 2. 做论文选题时

优先从以下方向中选择：

- 存量建筑室内空间资源再利用。
- 地域文化空间设计与文化转译。
- 疗愈景观与复愈性环境理论。
- 儿童友好与亲自然景观设计。
- AIGC 辅助传统文化空间设计。

### 3. 做阅读笔记时

建议统一使用以下格式：

```text
文献题名：
作者 / 年份 / 期刊：
研究对象：
核心问题：
理论基础：
研究方法：
主要创新点：
知识体系：
可借鉴之处：
可发展论文题目：
```
