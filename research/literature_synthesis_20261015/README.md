## 总体知识框架

价值目标（人本、生态、文化） → 对象与场景（建筑/室内/过渡空间/景观） → 问题识别 → 理论解释 → 调研与约束 → 设计转译 → 评价反馈。

本框架由整理者综合建立，与第11篇作者的三层理论框架分别标注。

### 六个相互连接的主题

- 资源循环：01连接材料生命周期和存量更新。
- 适应性空间：02、03连接活动需求、空间复合与切换成本。
- 环境性能：05连接室内外界面、气候和使用行为，证据待补。
- 健康与自然：06、07、09连接不同人群、自然接触和恢复体验。
- 文化转译：04、08、10连接文化识别、空间表达与参与评价。
- 理论与数字方法：11提供本土理论讨论，12提供文化与空间约束的生成机制。

### 可形成的交叉研究

1. 01+02+03：可拆卸家具与空间切换是否同步降低改造负担和使用成本？以材料清单、切换记录和使用评价验证。
2. 04+08+10+12：文化元素如何从资料、权重转为空间规则，再以使用者理解检验？比较有无文化规则的方案。
3. 06+07+09：不同年龄、活动和感官需求怎样影响自然空间使用？先比较场景差异，不能直接合并为统一疗愈效应。
4. 05+07：室内外过渡界面的环境舒适度与庭园可达性怎样共同影响使用？须先补齐05原文。
5. 11+12：本土理论如何成为可解释的生成约束？避免把审美符号当作完整知识体系。

## 统一研究实施框架

界定一个场地和人群 → 补齐原文并逐条建立证据表 → 选择明确比较对象 → 操作化变量 → 调研或实验 → 对照评价 → 分析边界 → 输出设计策略。

建议论文六章：绪论；文献与概念；变量和方法；案例/实验；设计应用与评价；结论与限制。每一条创新主张均应回答：相对谁、改变什么、凭什么证据、何时失效。
