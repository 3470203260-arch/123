# 文献精读：旧物新生——存量建筑与室内设计中的资源再利用路径

整理日期：2026-10-11

## 一、选定文献

**周艺君：《旧物新生——存量建筑与室内设计中的资源再利用路径》，《设计》，2024。**

PDF 链接：  
https://pdf.hanspub.org/design202496_1421181593.pdf

原文献库分类：室内设计 / 存量更新  
原文献库学习重点：旧建筑更新、材料再利用、循环经济、绿色室内设计。

## 二、为什么选这篇

这篇文献适合做室内设计方向的研究生文献精读，因为它把“旧物再利用”从装饰层面的怀旧风格，提升到了资源循环、存量更新和可持续设计的方法问题。

它的价值主要体现在：

1. **研究对象贴近现实**：城市进入存量更新阶段，大量旧建筑、旧材料、旧家具和旧构件需要被重新利用。
2. **主题具有可持续意义**：文章关注建筑废弃物、材料生命周期、低碳设计和循环经济。
3. **适合形成设计方法**：可以从材料、空间、技术、管理和市场五个方面建立研究框架。
4. **可转化为论文选题**：适合发展为存量建筑改造、旧材料再设计、绿色室内设计评价体系等方向。

## 三、核心研究问题

这篇文献可以概括为一个核心问题：

**在城市存量更新背景下，室内设计如何通过资源再利用实现空间更新、材料循环和可持续发展？**

可以拆成四个子问题：

1. 旧建筑和旧空间如何重新激活。
2. 旧材料、旧家具、旧构件如何再设计和再利用。
3. 数字技术如何帮助材料记录、追踪、评估和管理。
4. 资源再利用如何从设计理念转化为可实施、可推广的设计路径。

## 四、主要创新点

### 创新点 1：从“旧物装饰”转向“资源循环系统”

传统室内设计中，旧材料常被当作风格元素，例如复古、怀旧、工业风。但这篇文献的重点不是把旧物当装饰，而是把旧物视为可循环利用的空间资源。

可提炼为：

```text
旧物作为装饰符号
→ 旧物作为材料资源
→ 旧物作为空间记忆
→ 旧物作为低碳设计路径
→ 旧物作为循环经济节点
```

创新意义：

- 拓展了室内设计的资源观。
- 把旧物再利用与低碳、环保、循环经济联系起来。
- 让设计从“表面风格”进入“材料生命周期管理”。

### 创新点 2：把存量建筑更新与室内设计结合起来

文章不是孤立讨论室内软装或材料，而是放在存量建筑更新的大背景下。旧建筑的结构、材料、空间记忆和使用功能都可以成为再设计资源。

创新意义：

- 室内设计不再只是新建空间的后期装修。
- 室内设计可以参与城市更新和旧建筑活化。
- 存量空间的历史痕迹、材料质感和原有构件可以转化为设计价值。

### 创新点 3：提出多层次资源再利用路径

文章中的资源再利用不是单一路径，而是可以从多个层次展开：

| 层次 | 再利用对象 | 设计方式 |
|---|---|---|
| 材料层 | 木材、砖、金属、玻璃、构件 | 清理、修复、再加工、重组 |
| 家具层 | 旧家具、旧设备、旧陈设 | 改造、拼接、功能转换 |
| 空间层 | 旧厂房、旧商业、旧住宅 | 功能置换、动线重构、空间激活 |
| 文化层 | 历史记忆、场所精神 | 保留痕迹、叙事表达、情感认同 |
| 管理层 | 材料信息、生命周期数据 | 材料护照、数字孪生、数据库管理 |

创新意义：

- 让“旧物新生”从口号变成可拆解的方法体系。
- 便于研究生论文建立指标和章节结构。
- 可以形成设计策略、评价标准和案例分析框架。

### 创新点 4：关注数字技术在资源再利用中的作用

文章提到材料护照、数字孪生等技术思路，说明旧材料再利用并不只是手工经验，也可以借助数字化方法进行记录、追踪和评估。

创新意义：

- 把传统旧物改造与数字化管理结合起来。
- 可以记录材料来源、性能、使用状态、再利用方式。
- 为低碳设计、绿色认证和材料数据库建设提供可能。

可转化为研究路径：

```text
旧材料采集
→ 材料信息记录
→ 性能与安全评估
→ 再设计匹配
→ 空间应用
→ 后期维护与再循环
```

### 创新点 5：强调灵活空间与可持续使用

资源再利用不只发生在材料层面，也发生在空间功能层面。存量建筑改造中，空间需要具备更强的适应性，支持未来功能变化，减少重复拆改。

创新意义：

- 把“材料可持续”扩展到“空间可持续”。
- 通过可变家具、模块化构件、灵活隔断等方式延长空间生命周期。
- 减少未来装修拆除带来的资源浪费。

### 创新点 6：把资源再利用与市场推广联系起来

旧物再利用要真正落地，不能只靠设计师理念，也需要消费者接受、企业参与、政策支持和市场机制。

创新意义：

- 让可持续设计从概念走向应用。
- 强调公众环保意识、品牌价值和商业模式的重要性。
- 有助于形成“设计—生产—消费—回收”的闭环。

## 五、知识体系框架

这篇文献可以整理成一个“六层知识体系”：

```text
1. 背景层：为什么需要资源再利用
2. 对象层：哪些资源可以再利用
3. 方法层：如何再利用
4. 技术层：如何管理和评估
5. 评价层：如何判断再利用效果
6. 应用层：如何转化为论文或设计实践
```

### 1. 背景层：为什么需要资源再利用

- 城市从增量建设转向存量更新。
- 建筑和装修废弃物增加。
- 室内设计需要回应低碳和可持续发展。
- 旧建筑、旧材料和旧家具具有再利用价值。

### 2. 对象层：哪些资源可以再利用

- 旧建筑结构：墙体、梁柱、楼梯、屋架。
- 旧材料：木材、砖石、金属、玻璃、陶瓷。
- 旧家具：桌椅、柜体、灯具、门窗。
- 旧空间：厂房、仓库、商业空间、住宅空间。
- 旧记忆：历史痕迹、场所故事、使用者情感。

### 3. 方法层：如何再利用

```text
保留
→ 修复
→ 改造
→ 重组
→ 功能转换
→ 艺术化表达
→ 系统化管理
```

对应设计策略：

| 方法 | 说明 |
|---|---|
| 原样保留 | 保留旧建筑痕迹和材料质感 |
| 修复再用 | 对旧材料进行清洁、加固、修补 |
| 拆解重组 | 将旧构件拆解后用于新空间 |
| 功能转换 | 把旧物转化为新的家具或空间构件 |
| 混搭表达 | 新旧材料并置，形成时间层次 |
| 模块化利用 | 让构件可拆卸、可替换、可再次使用 |

### 4. 技术层：如何管理和评估

- 材料护照：记录材料来源、性能、使用年限和再利用方式。
- 数字孪生：建立建筑和材料的数字模型，辅助维护和更新。
- 生命周期评估：分析材料从生产、使用到回收的环境影响。
- 数据库管理：建立旧材料资源库，方便设计师选择和匹配。

### 5. 评价层：如何判断再利用效果

可以建立五类指标：

| 评价维度 | 评价问题 |
|---|---|
| 环境效益 | 是否减少新材料使用和建筑垃圾 |
| 空间效益 | 是否改善空间功能和使用体验 |
| 文化效益 | 是否保留场所记忆和历史特征 |
| 经济效益 | 是否降低成本或创造商业价值 |
| 可持续效益 | 是否便于后期维护、拆卸和再次利用 |

### 6. 应用层：可以延伸的研究方向

- 城市更新背景下存量建筑室内资源再利用策略研究。
- 基于循环经济的室内旧材料再设计研究。
- 旧工业建筑改造中的材料再利用与空间叙事研究。
- 绿色室内设计中材料护照应用研究。
- 存量商业空间更新中的旧构件再利用研究。

## 八、一句话总结

这篇文献的创新不只是“把旧东西重新用起来”，而是提出了一种思路：

**把存量建筑中的旧材料、旧空间和旧记忆转化为可识别、可设计、可管理、可评价的可持续室内设计资源。**
