## 建议阅读顺序

1. 先读文献总览，了解有哪些研究方向。
2. 再读“旧物新生”精读，学习如何从一篇文献提炼创新点和论文框架。
3. 再读“AIGC 古典园林”精读，学习如何把技术前沿和传统文化结合成研究方向。
4. 后续每读一篇新文献，都按“研究问题—创新点—知识体系—论文框架”的格式整理。

## 可继续发展的研究方向

- 城市更新背景下存量建筑室内空间资源再利用策略研究。
- 基于地域文化转译的餐饮空间或公共空间设计研究。
- 复愈性环境理论下校园或医院疗愈景观设计研究。
- 儿童友好导向下社区亲自然游戏景观设计研究。
- AIGC 辅助传统文化空间生成与评价方法研究。
